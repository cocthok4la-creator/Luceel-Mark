Frequently asked questions

Quick answers about making, testing and printing your code.

What can I put in a QR code?
Here you can encode a web address, plain text, email, phone number, Wi-Fi details, WhatsApp chat, UPI payment, contact card, social profile, map location or calendar event.
Are these QR codes free to download?
Yes. Downloading PNG, SVG and PDF files here doesn’t require an account.
Can a QR code stop working?
The code itself doesn’t expire, because it contains your content directly. It can stop being useful if the website it points to goes away, or if the printed code gets damaged or smudged.
Why should I test the code before printing it?
Devices and scanner apps differ. Test at the size you intend to print, on the real background, with more than one phone if you can.
What file format should I use for print?
SVG is the safest choice because it stays sharp at any size. If you use PNG, keep it at its original size or smaller rather than enlarging it.
Does changing the colors affect scanning?
It can. Keep a dark code on a light background with strong contrast. Light codes on dark backgrounds and low-contrast pairs fail on some scanners, and the page warns you when contrast is low.

  • The page loads fonts from Google Fonts and code libraries from cdnjs, so those services can see your IP address and browser details, as with most websites.
